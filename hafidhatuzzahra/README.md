# Kartu Cinta (Postcard Animasi)

Versi ini adalah versi animasi bertema "postcard" — ada efek flip 3D, teks diketik saat membuka, efek hati saat diklik, dan confetti saat menekan tombol "Kirim Cinta".

Cara pakai:
- Buka `index.html` di browser (klik dua kali atau pilih Open File di browser).
- Klik tombol "Buka Surat" untuk melihat pesan; klik "Kirim Cinta" untuk confetti.
- Untuk mengganti foto depan, ganti file `images/photo1.svg` dengan foto Anda (jpg/png) dan beri nama yang sama, atau ubah atribut `src` di `index.html`.

Catatan teknis:
- Dibangun dengan HTML/CSS/JS murni; tidak butuh server.
- Desain responsif — ukuran kartu menyesuaikan layar ponsel dan desktop.
- Aksesibilitas dasar: tombol dapat difokuskan; `Escape` menutup kartu; Enter dapat toggle bila fokus di dalam kartu.

Jika Anda ingin saya mengganti placeholder SVG dengan foto asli Anda, upload foto di sini (atau beri tahu nama file) dan saya akan menyesuaikannya: crop, replace, dan tes di mobile.

Opsi tambahan yang bisa saya tambahkan:
- Tambah font kustom atau lebih banyak animasi (mis. background bintang bergerak).
- Ekspor sebagai single-file HTML (semua CSS/JS inline) untuk memudahkan pengiriman lewat pesan.
- Deploy ke GitHub Pages dan beri URL publik.

Jika mau, balas "Ganti foto" dan unggah fotonya, atau beritahu warna/pesan yang ingin Anda ubah.
