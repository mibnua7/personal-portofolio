Smart Farm

Kategori: IoT / Microcontroller | Tahun: 2024 | Platform: Arduino IDE

Tentang Proyek Ini

Proyek "Smart Farm" adalah sistem pemantauan dan otomasi pertanian berbasis IoT yang dirancang untuk mengoptimalkan kondisi pertumbuhan tanaman melalui monitoring kelembapan tanah dan suhu lingkungan secara real-time.

Fitur Utama

  • Sensor kelembapan tanah untuk monitoring kondisi media tanam
  • Sensor suhu dan kelembapan udara (DHT22)
  • Sistem penyiraman otomatis berdasarkan kondisi tanah
  • Notifikasi IoT melalui aplikasi mobile
  • Data logging untuk analisis pertumbuhan

Teknologi yang Digunakan

  • ESP32 sebagai mikrokontroler utama
  • Sensor kelembapan tanah kapasitif
  • Sensor DHT22 untuk suhu dan kelembapan
  • Relay module untuk kontrol pompa air
  • Platform IoT Blynk untuk monitoring
